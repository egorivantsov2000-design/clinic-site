# Сайт клиники «Тихая» 

## Цель работы: 
Ознакомиться и на практике применить знания структуры HTML-страницы, форм и селекторов. 

## Задание: 
Внедрить в разрабатываемый проект правильную структуру HTML-страницы, разработать формы, использовать селекторы. 

## О проекте: 
Многостраничный сайт частной клиники. 
Вёрстка выполнена на HTML5 с использованием фреймворка Bootstrap 5.3. 
Макет взят из Figma. 
```bash
## Структура проекта: 
clinic-site/ 
├── index.html      # Главная 
├── about.html      # О клинике 
├── services.html   # Каталог услуг 
├── service.html    # Страница услуги 
├── doctors.html    # Список врачей 
├── doctor.html     # Страница врача 
├── booking.html    # Запись на приём 
├── contacts.html   # Контакты 
├── style.css       # Собственные стили поверх Bootstrap 
└── img/            # Изображения
```
